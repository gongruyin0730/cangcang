# 信源优先级与检索方法

## 优先级

1. 各国政府、央行、统计局、财政部、债务管理机构和选举机构。
2. 欧盟委员会、欧洲央行、Eurostat、欧洲理事会及相关欧盟机构。
3. IMF、世界银行、OECD、EBRD、BIS 等国际组织。
4. 标普、穆迪、惠誉、DBRS Morningstar 等评级机构原始公告。
5. 路透社、AP、AFP 等可靠国际通讯社及具有公信力的全国性媒体。

官方来源确认事实和数字，媒体来源补充背景与市场反应。新闻稿转载不得替代原始公告，除非原文不可访问，并在来源清单中说明。

## 检索组合

每个国家至少覆盖当地英文名、常用本地名称和以下主题词的组合：

`GDP`, `inflation`, `CPI`, `central bank`, `interest rate`, `budget`, `deficit`, `government debt`, `bond`, `current account`, `trade`, `energy`, `election`, `government`, `EU`, `IMF`, `credit rating`, `outlook`。

同时限定起止日期，并分别检索官方站点与新闻媒体。搜索结果摘要只用于发现线索，最终引用实际页面。

## 核验规则

- 关键数字核对原始表格、公告或统计发布，不只依赖新闻标题。
- 区分发布日、数据期和事件日。
- 区分名义值与实际值、同比与环比、季调与未季调、实际值与预测值。
- 涉及评级时记录评级对象、长期或短期、本币或外币、级别、展望、行动日期及主要理由。
- 页面内容与发布日期不清晰时，不把搜索引擎抓取日期当作新闻发布日期。
- 访问受限时寻找同一机构的 PDF、新闻稿镜像或可靠媒体报道，并披露限制。
